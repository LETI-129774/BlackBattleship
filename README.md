Product Backlog — papergames.io

Introdução

O papergames.io é uma plataforma online que disponibiliza vários jogos de tabuleiro e entretenimento, permitindo aos utilizadores jogar contra amigos, adversários aleatórios ou inteligência artificial. A plataforma disponibiliza funcionalidades de comunicação, gestão de amigos, histórico de partidas, torneios, classificações, loja virtual e subscrições.

Scrum User Stories

1. Acesso à plataforma e jogos

US01 — Aceder à plataforma

Como utilizador, quero aceder à plataforma papergames.io através de um navegador, para poder utilizar os serviços e jogos disponíveis.

US02 — Consultar os jogos disponíveis

Como utilizador, quero visualizar os jogos disponíveis na plataforma, para poder escolher aquele que pretendo jogar.

US03 — Consultar as regras dos jogos

Como jogador, quero consultar as regras e instruções dos jogos, para compreender o seu funcionamento antes de começar a jogar.

US04 — Jogar como convidado

Como utilizador, quero poder jogar sem criar uma conta, para participar numa partida de forma rápida e simples.

US05 — Jogar contra um robot

Como jogador, quero jogar contra um adversário controlado pela inteligência artificial, para poder praticar sem precisar de outro jogador.

US06 — Jogar contra um adversário aleatório

Como jogador, quero ser emparelhado automaticamente com outro utilizador disponível, para participar numa partida online.

US07 — Jogar com um amigo através de um convite

Como jogador, quero criar uma partida e partilhar um link único, para convidar outra pessoa a jogar comigo.

2. Jogo Battleship (Batalha Naval)

US08 — Iniciar uma partida de Batalha Naval

Como jogador, quero iniciar uma partida de Batalha Naval contra um amigo, um robot ou um adversário aleatório, para participar num jogo.

US09 — Visualizar o tabuleiro de jogo

Como jogador, quero visualizar o meu tabuleiro e o tabuleiro do adversário, para acompanhar o desenvolvimento da partida.

US10 — Posicionar os navios

Como jogador, quero ter uma frota de cinco navios distribuída pelo meu tabuleiro, para poder participar na batalha naval.

US11 — Efetuar disparos

Como jogador, quero selecionar uma posição no tabuleiro adversário e efetuar um disparo, para tentar atingir os navios inimigos.

US12 — Identificar disparos acertados e falhados

Como jogador, quero visualizar os resultados dos disparos, distinguindo os acertos dos disparos na água, para acompanhar o progresso da partida.

US13 — Utilizar armas especiais

Como jogador, quero utilizar diferentes tipos de mísseis, incluindo mísseis grandes, chuva de mísseis e mísseis nucleares, para atingir diferentes posições do tabuleiro adversário.

US14 — Recolher presentes durante a partida

Como jogador, quero recolher presentes que aparecem no tabuleiro através dos meus disparos, para obter armas adicionais.

US15 — Identificar o vencedor da partida

Como jogador, quero receber uma indicação do resultado final, para saber se consegui afundar toda a frota adversária.

3. Comunicação e amigos

US16 — Aceder à área de conversação

Como utilizador, quero aceder à área de chat da plataforma, para consultar as funcionalidades de comunicação disponíveis.

US17 — Enviar mensagens no chat

Como utilizador, quero enviar mensagens a outros jogadores, para comunicar com eles durante a utilização da plataforma.

US18 — Receber mensagens

Como utilizador, quero receber mensagens de outros jogadores, para acompanhar as conversas iniciadas comigo.

US19 — Utilizar emojis durante as conversas

Como jogador, quero utilizar emojis nas minhas interações, para expressar reações durante as partidas e conversas.

US20 — Consultar a lista de amigos

Como utilizador, quero consultar a área dos meus amigos, para acompanhar as minhas ligações com outros jogadores.

US21 — Interagir com os amigos

Como utilizador, quero poder utilizar as funcionalidades disponíveis na área de amigos, para manter contacto com outros jogadores da plataforma.

US22 — Garantir a moderação das mensagens

Como utilizador, quero que mensagens que violem as regras de utilização sejam moderadas, para manter um ambiente de comunicação adequado.
